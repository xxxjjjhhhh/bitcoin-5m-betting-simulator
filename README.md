# Crypto Direction Predictor

一个零依赖的单文件加密货币涨跌预测面板。直连币安公共行情接口，实时展示 K 线、盘口、逐笔成交，
并在每根 K 线收盘时自动锁定预测、到期结算、累计命中率。

支持 **10 个主流币种**、**7 档图表周期**、**3 种预测模式**、**5 种界面语言**。

## 功能

- **多币种**：BTC / ETH / SOL / BNB / XRP / DOGE / ADA / AVAX / LINK / TRX
- **三种预测模式**
  - 1 分钟：每根 1m K 线收盘锁定，下一分钟结算
  - 5 分钟：只在 :00/:05/:10… 整点锁定，5 分钟后结算
  - 区间：在 5m / 15m / 1h 区间内持续更新「收盘价是否会高于开盘价」的概率
- **图表周期**：1m / 5m / 15m / 30m / 1h / 4h / 1d，长周期实时增量合并
- **多语言**：简体中文 / English / 日本語 / 한국어 / Русский
- **接口区域**：全球站（binance.com）/ 美国站（binance.us）
- **自动结算**：预测与结果逐条记录，命中率、连胜、对比 50% 基线
- **离线降级**：推送断开自动重连 → 降级 REST 轮询 → 完全断网可进演示模式

## 运行

```
双击 启动.bat
```

会用本地 `python -m http.server` 起服务，再用无地址栏的 Chrome 窗口打开。
也可以直接用浏览器打开 `index.html`（需允许本地文件访问网络）。

## 数据来源

币安公共行情接口（只读，无需 API Key，不涉及任何交易）：

- WebSocket `wss://data-stream.binance.vision` 实时 K 线 + 逐笔成交 + 盘口
- REST `https://data-api.binance.vision` 历史 K 线、24h 统计、深度快照

## 已知限制

这个工具的价值在于**把盘口、成交、动量这些瞬时信息结构化呈现**，不是保证胜率。

用一年真实数据做过严格回测（见 `model/训练报告.md`）：

- 1 分钟方向预测的滚动前向命中率约 **52.7%**，5 分钟约 **52.0%**
- 平均每分钟绝对波动约 0.038%，方向正确时的期望毛收益约 0.0021%
- 币安 taker 往返手续费 0.10%，**毛收益只有成本的 2.1%**

结论：**统计上有效，但扣掉手续费后不可交易**。请勿据此直接下单，本项目不构成任何投资建议。
